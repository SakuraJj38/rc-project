Connection Details

1. Battery Connections:

  • Battery positive (+) → 60A ANL Fuse → Main power switch
  • Battery negative (-) → Common ground bus

2. ESC Connections:

  • ESC input (+) → Main power switch output
  • ESC input (-) → Common ground
  • ESC motor outputs → MY1016Z motor terminals (3 wires)
  • ESC servo signal → Channel 2 on receiver

3. Wireless Control Setup:

Channel 1: Steering Servo
Channel 2: ESC Throttle Control 
Channel 3: Gear Shift Servo
Channel 4: Light System Control
Channel 5: Sound System Control

Safety Notes

  • Always connect transmitter first, then battery
  • Use 10AWG wire for battery to ESC connections
  • Verify all polarities before powering on

12V 40Ah Lithium-Ion Battery Pack Construction

Cell Configuration: 3S12P (3 Series 12 Parallel)

[ 18650 Cell (3.7V 3400mAh) ]  [ 18650 Cell ]  ... (12 cells in parallel)
[ 18650 Cell (3.7V 3400mAh) ]  [ 18650 Cell ]  ... (12 cells in parallel)
[ 18650 Cell (3.7V 3400mAh) ]  [ 18650 Cell ]  ... (12 cells in parallel)

Total: 36 cells (3 series × 12 parallel)

Construction Steps

1. Cell Preparation:

  • Select matched 18650 cells (same brand, capacity, and age)
  • Test each cell voltage (should be 3.6V-3.7V when new)
  • Label cells for proper grouping

2. Parallel Group Assembly (12P):

  • Connect 12 cells in parallel (all + terminals together, all - terminals together)
  • Use nickel strip (0.15mm × 7mm recommended)
  • Spot weld connections (do not solder directly to cells)
  • Repeat to make 3 identical parallel groups

3. Series Connection (3S):

  • Connect parallel groups in series: 
    [Group 1 +] --- [Group 2 -] 
[Group 2 +] --- [Group 3 -]
  • Final voltage: 11.1V nominal (12.6V fully charged)
  • Final capacity: 40.8Ah (3400mAh × 12)

4. Protection Circuit Installation:

  • Connect 3S BMS (Battery Management System): 
    BMS Connections:
B-  → Battery negative (first parallel group)
B1 → Between 1st and 2nd series group
B2 → Between 2nd and 3rd series group
B+  → Battery positive (last parallel group)
P-  → Output negative
P+  → Output positive
  • Use 40A continuous rated BMS
  • Secure all connections with heat shrink tubing

Critical Safety Precautions

  • ALWAYS use spot welder - never solder directly to 18650 cells
  • Use protective glasses when assembling
  • Test each parallel group voltage before series connection
  • Balance charge for first 5 cycles
  • Never discharge below 9V (3V per cell)

Quality Verification Methods

1. Motor Verification:

  • Check for copper windings (not aluminum)
  • Look for genuine brand markings
  • Verify shaft diameter matches specs (10mm for MY1016)

2. Battery Authentication:

  • Request factory test reports
  • Check for consistent welding spots
  • Verify weight (48-50g for genuine 18650 3400mAh)

3. ESC Quality Checks:

  • Inspect MOSFET quality (should be branded)
  • Check heat sink thickness (minimum 2mm)
  • Verify wire gauge (10AWG for 60A models)
